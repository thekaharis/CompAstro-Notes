## Codes & Tools
- [[py21cmfast]] — Python wrapper for 21cmFAST; group's primary simulation code
- [[BEoRN]] — Schosser et al. 2023; halo-profile semi-numerical code; second code for P1/P2 (replaced SCRIPT, which is no longer publicly available)
- [[swyft]] — TMNRE SBI framework; planned inference tool for P2
- [[powerbox]] — power spectrum utilities for EFT coefficient extraction
- [[THESAN]] — radiative transfer hydrodynamical code; used in Qin et al. 2022
- [[EoRFlow]] — Heidelberg SBI framework; reconstructs $x_\text{HI}(z)$ from 2DPS
- [[SKATR]] — Heidelberg self-supervised ViT; cross-simulator generalization
